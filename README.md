# TPrompt – приложения за Windows и Android

Телепромптър с редактор, отметки, огледален режим, втори прозорец за втори монитор и **дистанционно управление от Android приложението**.
Целият интерфейс е в един файл – [`www/index.html`](www/index.html). Този проект го опакова като:

- **Windows** (x64) – [Tauri](https://tauri.app): инсталатор `.exe`, **около 5 MB**;
- **Android** – Capacitor: `.apk`.

Не са нужни Android Studio или Windows на вашия компютър. GitHub Actions строи и двете.

## Как да вземете готови файлове

1. Качете проекта в нов репозиторий в GitHub (включително скритата папка `.github`).
2. **Actions → Build → Run workflow**. След няколко минути `.exe` и `.apk` са в **Artifacts**.
   Първият билд на Windows е по-бавен (Rust компилира Tauri), следващите са по-бързи.
3. За публикуване на версия: `git tag v1.0.0 && git push --tags`. Билдът прикачва файловете към **Releases**.

Windows версията ползва WebView2, който е вграден в Windows 10 (последните версии) и Windows 11.
Инсталаторът го сваля сам, ако липсва.

## Remote: телефонът или таблетът като дистанционно

1. На компютъра (Windows) натиснете **Пусни → Дистанционно** в лентата с бутони: показва се QR код.
2. В Android приложението натиснете **Пусни → Дистанционно → Сканирай QR код** (или поставете адреса на ръка).
3. Текстът се редактира на телефона и се показва на компютъра във втория прозорец (на втория монитор на цял екран, ако има такъв).

Екранът на телефона е разделен: **горе** е панел (редактор, отметки или настройки), **по средата** е превюто в реално време, **долу** са големи бутони за палеца
(пускане и пауза, скорост +/−, размер на текста +/−, затваряне на прозореца на компютъра). Лентата с бутони е същата като без връзка: **Отметки** и **Настройки** сменят панела горе, а още едно натискане връща редактора.
Къде се чете, се избира от менюто **Пусни**: **Цял екран** (на това устройство), **В прозорец** (само Windows) и **Дистанционно**. В Windows бутонът **Дистанционно** до менюто показва текста на телефона. В Android, след като устройствата са свързани, **Дистанционно** показва или затваря прозореца на компютъра, без нова връзка, а **Цял екран** чете на телефона, докато компютърът управлява. Устройството, на което не се чете, става управление: превю, отметки, настройки. Без връзка Android приложението е самостоятелен телепромптър.
Ако отворите адреса в обикновен браузър на телефона, получавате облекчена страница само с превю и управление.

Условия: устройствата са в една Wi‑Fi мрежа. При първо включване Windows пита за достъп до мрежата: разрешете.
QR кодът остава същият при всяко пускане на приложението и се сменя само с „Нов код“. Данните не минават през интернет.
Ако компютърът има няколко мрежови адаптера (VPN и др.), проверете, че адресът под QR кода е от вашата Wi‑Fi мрежа.

## Позиция на прозорците (Windows)

Главният и вторият прозорец помнят последната си позиция и размер (`%APPDATA%\com.tprompt.app\windows.json`).
Вторият прозорец се отваря на цял екран на втория монитор, ако е закачен; ако не е, се отваря на основния.
Прозорец, останал на разкачен монитор, се връща на видим екран.

## Как да го пуснете на вашия компютър

Нужни са Node.js 20+ и [Rust](https://rustup.rs). На Windows е нужен и Visual Studio Build Tools (C++).

```bash
npm install
npm start               # стартира Windows версията в режим за разработка
npm run dist:win        # строи инсталатор в src-tauri/target/release/bundle/nsis
```

За Android (Android Studio и JDK 21):

```bash
npx cap add android     # само първия път
npm run icons           # икони от папка assets
npm run android:sync    # копира www в приложението
npm run android:open    # отваря в Android Studio
```

## Как се променя приложението

Редактирайте само `www/index.html` и качете промените. Папката `www` се ползва и от двете платформи.

## Особености по платформи

| | Windows | Android |
|---|---|---|
| Пусни → Цял екран | да | да |
| Пусни → В прозорец / втори екран | да, на другия монитор на цял екран | не е смислено, бутонът е скрит на тесен екран |
| Remote (компютърът е дисплей) | да, показва QR кода | да, телефонът/таблетът управлява; сканира QR |
| Клавишни комбинации | да | с външна клавиатура |
| Запазване на файл | диалог „Запази като“ | зависи от Android WebView, проверете преди да разчитате на него |
| Отваряне на .docx | работи и без интернет | работи и без интернет |

Текстът и настройките се пазят във вътрешното хранилище на приложението. Ако го деинсталирате, те се губят,
затова запазвайте важните текстове като .html.

## Диагностика

В Windows приложението F12 или десен клик → Inspect отваря конзолата. Така се виждат грешките, ако нещо не работи.

**Плавност при два прозореца.** `Ctrl+Shift+D` във всеки от прозорците показва малка лента с кадрите в секунда, най-дългия кадър и броя бавни кадри (над 25 мс). Ако четенето във втория прозорец още се накъсва, пуснете я и в двата прозореца по време на четене и сравнете числата.

## Подписване на Android (за Google Play)

Билдът прави **debug APK**, който може да се инсталира директно. За Google Play е нужен подписан **release** пакет:
създайте keystore, добавете го като secret в GitHub и сменете `assembleDebug` с `bundleRelease` в
`.github/workflows/build.yml` със signing config в `android/app/build.gradle`.

## Структура

```
www/index.html          цялото приложение
src-tauri/              Windows обвивка (Tauri, Rust)
  src/main.rs           прозорци, втори монитор, запазване на файл
  src/remote.rs         сървър за дистанционното (само стандартна библиотека)
  remote.html           страницата, която се отваря на телефона
capacitor.config.json   Android обвивка
assets/, build/         икони
.github/workflows/      build.yml (.exe + .apk), check.yml (проверка на кода)
```
